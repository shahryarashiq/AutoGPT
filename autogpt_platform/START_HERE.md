## 🔑 About API Keys

### Do I NEED API keys?

**No!** You can use demo mode without any keys.

### When should I get API keys?

Get them when you want **real jobs** instead of demo jobs.

### Which API should I use?

**Indeed** (if you have an Indeed account):
- ✅ Easiest: Just need a Publisher ID
- ✅ Takes 2 minutes
- ✅ Free forever
- ✅ Great for Dubai jobs

**Adzuna** (if you don't have Indeed):
- ✅ Also free
- ✅ No account needed
- ✅ Works in UAE

### How to get Indeed Publisher ID?

See: **HOW_TO_GET_INDEED_API.md** (step-by-step with pictures)

Quick version:
1. Go to: https://www.indeed.com/publisher
2. Sign in with your Indeed account
3. Register (fill simple form - 2 minutes)
4. Copy the big number (your Publisher ID)
5. Paste in dashboard → Platforms tab

## 🆘 Common Questions

### Q: Is this really free?

**A:** Yes! 100% free. Demo mode is free, Indeed Publisher ID is free, Adzuna is free.

### Q: I don't understand API keys. Can I still use this?

**A:** Yes! Just use demo mode. Skip the "Platforms" tab completely.

### Q: How do I get the Publisher ID? It's confusing.

**A:** See HOW_TO_GET_INDEED_API.md - it has pictures and step-by-step guide. Or just use demo mode!

### Q: Can I test without connecting anything?

**A:** Yes! Demo mode works immediately without any connection.

### Q: What's the difference between demo and real?

**A:** Demo shows example jobs. Real shows actual job postings you can apply to.

### Q: I want to connect LinkedIn/Indeed profile instead of API

**A:** Currently, the dashboard uses API keys for security. LinkedIn/Indeed don't allow direct profile connections for automation. But the API keys are free and easy to get!

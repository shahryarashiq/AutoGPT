# Job Hunt Dashboard - Quick Access

## 🎯 Dashboard URL

After starting the AutoGPT platform, access your Job Hunt Dashboard at:

**http://localhost:3000/job-hunt**

## ⚡ Quick Start (2 Minutes)

1. **Start Platform**:
   ```bash
   cd autogpt_platform
   docker compose up -d
   ```

2. **Open Dashboard**:
   - Go to: http://localhost:3000/job-hunt
   - Login if needed

3. **Add Your Resume**:
   - Click "Profile & Resume" tab
   - Paste your resume OR upload .txt file
   - Click "Save Profile"

4. **Search Jobs**:
   - Click "Job Search" tab
   - Add job titles: "Cashier", "Accountant"
   - Add locations: "Dubai, UAE", "Abu Dhabi, UAE"
   - Click "Search for Jobs"

## 🔑 Get Free API Access (5 Minutes)

For real job searches:

1. Go to: https://developer.adzuna.com/
2. Sign up (free, no credit card)
3. Create an application
4. Copy your App ID and App Key
5. In dashboard, go to "Platforms" tab
6. Paste credentials and click "Connect"

## 📱 Dashboard Features

✅ **Profile & Resume** - Upload and parse your resume  
✅ **Job Search** - Search multiple platforms at once  
✅ **Platform Connections** - Connect to Adzuna, Indeed, etc.  
✅ **Applications Tracker** - Monitor all your applications
